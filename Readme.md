Gestión de Licencias Médicas Estudiantiles

Descripción del Proyecto

El proyecto Gestión de Licencias Médicas Estudiantiles tiene como objetivo digitalizar y optimizar el proceso de solicitud, aprobación y
seguimiento de licencias médicas dentro de la comunidad estudiantil. La plataforma permitirá a los estudiantes enviar sus licencias médicas de 
manera segura, mientras que el personal administrativo podrá gestionar, validar y archivar estos documentos de forma eficiente.

El sistema incluye funcionalidades como:

   * Registro y autenticación de estudiantes y personal administrativo.

   * Subida y validación de documentos médicos.

   * Seguimiento del estado de las licencias.

   * Notificaciones automáticas sobre el estado de la solicitud.

   * Dashboard para visualizar estadísticas y reportes.

El proyecto está diseñado para ser escalable y adaptable a diferentes instituciones educativas, asegurando confidencialidad y cumplimiento de normativas de privacidad.

Tecnologías Utilizadas

   * Frontend: React con Tailwind CSS

   * Backend: Node.js con Express.js

   * Base de Datos: MySql

   * Almacenamiento de Archivos: Firebase

   * Autenticación y Validación: JSON Web Tokens (JWT)

Estas herramientas fueron seleccionadas por su flexibilidad, escalabilidad y facilidad de integración, permitiendo un desarrollo rápido y seguro de la plataforma.

Estructura del Proyecto

    /frontend      # Código de la aplicación web
    /docs          # Documentación adicional
